🚀 Quick start

  1. Open the Control Room on the operator's computer (or tablet/phone on the same network).
  2. Open the Program Output on the computer connected to the projector / streaming PC. Press F11 for full screen.
  3. Everything you do in the Control Room appears on every connected output instantly.
💡 This site is live on the internet — any phone, tablet or computer anywhere can open these pages. A phone opening the Control Room can broadcast its camera as an extra camera angle with “Presenter Cam”. Keep the Control Room link private: anyone who has it can operate your service.

📡 Go live on YouTube

  1. Install OBS Studio (free).
  2. In OBS add a Browser source: URL https://church-live-studio-png.web.app/output.html, width 1920, height 1080, and tick Control audio via OBS so worship music and videos are heard on the stream.
  3. In YouTube Studio click Create → Go live, copy the Stream key.
  4. In OBS: Settings → Stream → Service YouTube → paste the key → Start Streaming.

📘 Go live on Facebook

  1. On your church Page choose Live video → Go live → Streaming software.
  2. Copy the Stream key from Facebook Live Producer.
  3. In OBS: Settings → Stream → Service Facebook Live → paste the key → Start Streaming.
📡 Want YouTube and Facebook at the same time? Use OBS's Multiple Output plugin, or a restreaming service (Restream.io, Castr) — stream once to them and they forward to every platform.

🌍 Live translation

In the Control Room, pick the speaker's language and the target language, then press 🎙 Start listening. The browser transcribes the sermon through the microphone, auto-translates each phrase, and shows both as broadcast-style subtitles on the Program Output. Works best in Chrome or Edge with an internet connection.

🎥 Camera angles

  • Camera — any webcam/capture card plugged into the machine running the Program Output. Multiple cameras? Pick which one is live from the Control Room dropdown.
  • Presenter Cam — any phone/laptop on the same network opens the Control Room and broadcasts its camera to the output over WebRTC: an instant wireless camera angle.
  • Pro tip: for multi-camera productions, you can also do camera switching in OBS itself and use this app as your graphics layer (lyrics, ticker, captions) on top.

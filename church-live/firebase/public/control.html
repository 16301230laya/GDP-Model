      📡 Go Live on YouTube / Facebook

      1. Open Program Output full-screen, or add it in OBS Studio as a Browser Source (URL: https://church-live-studio-png.web.app/output.html, 1920×1080, ✔ control audio via OBS).
      2. In OBS: Settings → Stream → pick YouTube or Facebook Live and paste your Stream Key (from YouTube Studio “Go Live” / Facebook Live Producer).
      3. Press Start Streaming. To stream to several platforms at once use OBS multi-output or a restream service.

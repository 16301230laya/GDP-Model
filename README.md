# GDP Production Model

A production-approach (output) GDP model: enter **production quantities from
your commodity boards** and **prices**, and the model computes gross output,
gross value added, and GDP — nominal and real — automatically.

Two interchangeable front-ends share the same methodology:

1. **Excel workbook** — `GDP_Production_Model.xlsx` (generated by `build_model.py`)
2. **Web app** — `webapp/index.html`, a single offline-first HTML file
   pre-configured for **Papua New Guinea**

## Analysis dashboard: `analysis/GDP_2025_Analysis_Dashboard.xlsx`

A learning companion to the Treasury forecasting model (`GDP_model_forecasting_2025.xlsx`)
and the *GDP Model – Theory and Forecast* slides. It rebuilds the **2025 real GDP estimate**
step by step, the way the slides describe it:

| Tab | What it shows |
|---|---|
| `Guide` | The three GDP approaches, how the forecast works, colour code |
| `Dashboard` | Headline growth, contributions to growth by sector, nominal GDP, charts |
| `Resource` | DoT production volumes 2024 vs 2025 → resource GVA (real and nominal) |
| `AFF` | Commodity-board volumes for formal agriculture; informal activity grows with population |
| `Public_Admin` | Compensation of employees growth ÷ wage (deflator) growth |
| `Other_Sectors` | Population default growth, with a yellow column for your judgement overrides |
| `History` | 2006–2024 actuals plus the 2025 estimate |
| `Model_Check` | Gaps in the forecasting model that stop its 2025 column calculating |

Every result is a live formula; change a red/yellow input and the dashboard updates.
To rebuild it: `python3 analysis/build_dashboard.py` (reads `analysis/source_data.json`).

## The web app: `webapp/index.html`

Built for low-connectivity use: one file, no internet needed after it is
opened, runs in any modern browser on a phone, tablet or office PC.

- Pre-loaded PNG commodity register — coffee (Coffee Industry Corporation),
  cocoa (Cocoa Board), copra (KIK), palm oil (OPIC), rubber, tea, logs
  (PNG Forest Authority), marine products (NFA), gold, copper, nickel, silver
  (MRA), crude oil, LNG, condensate — all editable, values in Kina.
- Autosaves to the device as you type; JSON **backup/restore** moves the model
  between machines with no server involved.
- GDP summary (nominal, real, growth, deflator, per capita), charts, CSV
  export and a print-ready summary.
- "Load example numbers" fills clearly-labelled fake data for training.

To deploy: copy the single file to users however is convenient — USB stick,
email attachment, shared drive — and open it in a browser.

## The workbook: `GDP_Production_Model.xlsx`

| Sheet | What it does | Who fills it |
|---|---|---|
| `READ_ME` | Instructions and colour code | — |
| `Settings` | Country, currency, first year, constant-price **base year** | You |
| `Commodities` | Commodity register: sector, unit, IC ratio, source board (40 pre-wired slots) | You |
| `Production` | Yearly quantities per commodity | You (from commodity boards) |
| `Prices` | Yearly average price per unit | You |
| `Other_Sectors` | GVA entered directly for industries without commodity detail (manufacturing, services, government…) | You |
| `GVA_Nominal` | Quantity × Price × (1 − IC ratio) | Automatic |
| `GVA_Real` | Quantity × **base-year price** × (1 − IC ratio) | Automatic |
| `GDP_Summary` | GVA by industry, GDP at market prices (nominal + real), growth, deflator, per capita, sector shares | Automatic (plus taxes and population inputs) |
| `Dashboard` | Charts: nominal vs real GDP, real growth, GVA composition | Automatic |

**Colour code:** blue = input, grey = calculated (don't overwrite), amber = key result.

## Methodology

```
Gross Output (commodity)  = Quantity × Price
GVA (nominal)             = Gross Output × (1 − IC ratio)
GVA (real)                = Quantity × Base-year price × (1 − IC ratio)
GDP at market prices      = Σ GVA at basic prices + Taxes less subsidies on products
GDP deflator              = Nominal GDP / Real GDP × 100
```

The IC (intermediate consumption) ratio is the share of gross output used up
as inputs; it typically comes from supply-use tables or enterprise surveys.
Keep quantity and price units consistent (tonnes ↔ price per tonne).

The workbook ships with **example data** — replace it with your own.

## Everyday use (no coding needed)

- **Add a commodity:** type it on any empty row of `Commodities`, then enter
  its quantities and prices. Its name flows to every sheet and all totals and
  GDP update by themselves.
- **Change the base year or first year:** edit `Settings` — headers, real GVA
  and the deflator re-anchor automatically. Make sure the base year has prices
  filled in.

## Extending the model (regenerate the workbook)

The workbook is generated by `build_model.py`. Config lives at the top of the
script:

- `YEARS` — the year range
- `SECTORS` — commodity-producing sectors (drives the sector dropdown and summary rows)
- `OTHER_SECTORS` — industries entered as GVA directly
- `SEED_COMMODITIES` / `SEED_DATA` — the example register and data
- `N_COMMODITY_ROWS` — number of commodity slots

```bash
pip install -r requirements.txt
python3 build_model.py        # writes GDP_Production_Model.xlsx
```

Note: re-running the script rebuilds the workbook from the seed config, so
transfer any data you entered by hand before regenerating (or add it to
`SEED_COMMODITIES`/`SEED_DATA`).

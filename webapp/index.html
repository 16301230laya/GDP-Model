Welcome

This tool builds GDP by the production (output) approach: you enter production quantities from the commodity boards and average prices in Kina, and it calculates value added and GDP — nominal and real — automatically. It works completely offline and saves your data on this device as you type.

Five steps

  1. Settings — check the base year, first year and how values are displayed.
  2. Commodities — review the register: each commodity's sector, unit, intermediate-consumption (IC) ratio and source board. Add or remove rows as needed.
  3. Production & Prices — type the yearly quantities and prices from the board bulletins. Keep units consistent: if the quantity is in tonnes, the price is Kina per tonne.
  4. Other industries — enter value added directly for industries without commodity detail (manufacturing, construction, trade, government…).
  5. GDP Summary — read off GDP, growth, the deflator and per-capita GDP. Add taxes less subsidies on products and population there to complete the picture.

Your data stays on this device

Everything autosaves to this browser. To move the model to another computer, or keep a backup, download the data file and open it on the other machine with Restore backup. No internet connection is needed at any point.

Settings

These control the whole model. Changing the base year re-anchors real GDP instantly.

Commodity register

One row per commodity you track. The IC ratio is the share of gross output used up as inputs — value added = output × (1 − IC ratio). Typical values: 0.25–0.35 for agriculture, 0.35–0.45 for mining and petroleum.

Production quantities

From the commodity board bulletins. Units are shown per row — leave a cell empty if the figure is not yet available.

Prices (Kina per unit)

Yearly average price received, in Kina, per the same unit as the quantity. The column is used to value real GDP, so fill it for every commodity.

Other industries

Industries without commodity detail: enter their gross value added directly, in Kina — nominal (current prices) and real (constant base-year prices). Estimates from the national accounts or indicator-based projections both work.
